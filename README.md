# Н.О.Р.М. — локальный прототип

Самостоятельный React/Vite-прототип сайта «Ловцы Мистики» в виде внутренней системы Н.О.Р.М.

## Запуск

```bash
npm install
npm run dev
```

Затем откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Что уже есть

- экран допуска с активацией звука;
- кинематографическая оболочка Н.О.Р.М.;
- Сводка;
- Архив дел;
- Досье LM-006;
- Гримуар;
- Досье агентов;
- Архив материалов;
- FIELD TERMINAL;
- форма «Сообщить об аномалии»;
- чёрно-белые фотографии;
- процедурные UI-звуки через Web Audio API;
- анимации переходов, glitch, scanlines, grain;
- адаптивная мобильная версия;
- `noindex,nofollow` для локальной/тестовой стадии.

## Важно

Это прототип визуальной системы. Контент и характеристики Сена/Грига временные и должны быть заменены на канонические после разбора сценариев выпусков.
