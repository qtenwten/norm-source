# Н.О.Р.М. — local prototype

Интерактивный локальный прототип внутренней системы Н.О.Р.М. для проекта «Ловцы мистики».

## Запуск

```bash
npm install
npm run dev
```

Vite обычно открывает проект на `http://localhost:5173`.

## Что сейчас есть

- иммерсивный экран авторизации оператора;
- башенная эмблема Н.О.Р.М.;
- интерактивная сводка, реестр дел, досье агентов и архив материалов;
- кликабельные вкладки дела LM-006;
- иллюстрированный Гримуар с проявляемым служебным слоем;
- Field Terminal с настоящей командной строкой;
- чёрно-белые полевые фотографии;
- процедурный саунд-дизайн без постоянного белого шума;
- переходы, глитчи, сканирование, модальные просмотры и скрытые события.

## Команды Field Terminal

Начни с `HELP`.

Основные команды:

```text
HELP
STATUS
WHOAMI
SCAN
CLEAR
CASE LM-006
OPEN CASE LM-006
AGENT SEN
AGENT GRIG
GRIMOIRE
ENTITY P-017
ARCHIVE
SOUND ON
SOUND OFF
NORM
```

Есть и скрытая реакция на команду `WHO ARE YOU`.

## Важно

Некоторые скрытые агенты, служебные пометки и части содержимого LM-006 сейчас являются прототипным worldbuilding-контентом. Перед финальным релизом их нужно сверить с канон-библией и сценариями выпусков.
