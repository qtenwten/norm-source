# Н.О.Р.М. — интерактивная система «Ловцов мистики»

Веб-интерфейс внутренней системы Н.О.Р.М. для проекта **«Ловцы мистики»**. Это не обычный промосайт, а иммерсивная рабочая станция расследователя: дела, улики, досье агентов, архив, Гримуар, внутренняя почта, Media Forensics и Field Terminal связаны в одну интерактивную среду.

## Что уже реализовано

- театральная авторизация оператора с сохранением текущей сессии;
- башенная/радио-эмблема Н.О.Р.М. и единый classified-system UI;
- сводка и реестр дел с глубокими переходами между материалами;
- отдельные досье агентов, включая AG-SEN и AG-GRIG;
- расследовательская доска улик с пользовательскими связями;
- Media Forensics workstation для анализа полевых материалов;
- реестр оборудования и chain of custody;
- отдельная внутренняя почта с live-событиями и уведомлениями;
- иллюстрированный Гримуар с сущностями, связанными делами и скрытым служебным слоем;
- Field Terminal с историей команд, autocomplete, quick actions, скрытыми реакциями и ARG-событиями;
- процедурные системные события NORM-0 / GHOSTFS / MIRROR;
- кинематографические переходы, сканирование, viewer'ы, глитчи и интерактивные состояния;
- адаптивная компоновка для телефонов, планшетов, ноутбуков, Full HD и ultrawide;
- recovery-механизм для lazy-route чанков, чтобы открытая вкладка не превращалась в пустой экран после нового deploy.

## Дела

### LM-005 — «Ночной Душнила»

Дело собрано на основе выпуска «Сонный паралич» и использует реальные полевые кадры. Заполнены отчёт, хронология, улики, сущность и медиа; материалы связаны с общей навигацией, архивом и инструментами расследования.

### LM-006 — «Dead Inside»

Дело построено по сценарию выпуска: паттерн `1000−7`, Shadow Fiend, сообщение «УХОДИТЕ», ритуал, удаление Dota 2 и остаточный речевой паттерн. Медиа, которых нет в исходных материалах, не подменяются выдуманными «реальными» фотографиями.

## Звук

Аудиосистема теперь гибридная: **файловая production-библиотека + Web Audio**.

- 18 коротких SFX собраны в один sample-accurate audio sprite;
- WAV-библиотека детерминированно рендерится перед `dev`/`build`, поэтому Git не хранит тяжёлые бинарники;
- отдельные ambience-loop есть для серверной части, архива, Гримуара и терминала;
- реле, переключатели, бумага, архивный ящик, затвор камеры, штамп, радио, сканирование, переходы и аномальные события имеют собственные файловые слои;
- процедурный слой добавляет вариативность и остаётся fallback'ом, если файл не загрузился;
- пользовательская громкость зафиксирована на утверждённом уровне 100%; управление — только `ЗВУК ВКЛ/ВЫКЛ`.

Подробная карта библиотеки: [`docs/audio-library.md`](docs/audio-library.md).

## Field Terminal

Начни с:

```text
HELP
```

Базовые команды:

```text
STATUS
WHOAMI
SCAN
CLEAR
CASE LM-005
CASE LM-006
OPEN CASE LM-005
AGENT SEN
AGENT GRIG
GRIMOIRE
ENTITY P-017
ARCHIVE
SOUND ON
SOUND OFF
NORM
```

Терминал также понимает дополнительные Unix-like формы, Tab autocomplete и несколько скрытых команд/реакций. Не все ARG-механики документированы здесь намеренно.

## Локальный запуск

Требуется современный Node.js.

```bash
npm ci
npm run dev
```

Vite поднимет локальный сервер; адрес будет показан в терминале (обычно `http://localhost:5173`).

Production build:

```bash
npm run build
```

Pages build:

```bash
npm run build:pages
```

## Проверки

Перед публикацией CI проверяет HTTPS entry, audio policy, production audio library, responsive layout, route recovery, Field Terminal, workstation geometry, Investigation и N.O.R.M. 2.0 contracts, после чего собирает production bundle.

Ключевые команды:

```bash
npm run test:audio-policy
npm run test:audio-library
npm run test:responsive
npm run test:route-recovery
npm run test:terminal
npm run test:terminal-workstation
npm run test:investigation
npm run test:norm20
npm run build
```

## Архитектурный принцип

Контент и механики должны ощущаться как части одной секретной системы. Новые элементы лучше связывать с существующими делами, уликами, письмами, терминалом и архивом, а не добавлять как изолированные декоративные экраны.

Реальные фотографии и материалы не подменяются выдуманными «документальными» изображениями. Экспериментальный ARG/worldbuilding-контент должен оставаться явно отделимым от подтверждённого канона проекта.
